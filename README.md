# Verilog_practice

This repository contains my practice Verilog/SystemVerilog code as I learn digital design and HDL fundamentals. Each exercise is self-contained with its source module and, where applicable, a testbench.

## Topics Covered

- Combinational Logic
- Sequential Logic
- Multiplexers and Decoders
- Adders and Subtractors
- Counters
- Shift Registers
- Finite State Machines
- Testbenches
- RTL Design
- Verification

## Tools

- Verilog HDL
- Xilinx Vivado 2020.2
- Vivado Simulator

## Purpose

This repository documents my progression from basic Verilog programming to RTL design and verification concepts.
